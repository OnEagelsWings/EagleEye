# EagleEye Build 376.0 – Dossier vNext

Build 376 makes research completeness auditable. It adds source coverage states, source-class-aware staleness, bounded absence observations and explicit research gaps to the Evidence-first dossier while preserving the distinction between evidence, uncertainty and missing data.

Key safety semantics:
- coverage is not truth probability;
- absence is not non-existence;
- stale evidence is not automatically false;
- research gaps never auto-trigger crawler activity;
- human review remains required.
