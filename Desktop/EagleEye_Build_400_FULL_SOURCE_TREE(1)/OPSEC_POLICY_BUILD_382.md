# Defensive OPSEC Policy – Build 382

Build 382 adds durable source-planning metadata only. It grants no network or system-control authority.

- No autonomous firewall, OS, Tor, credential, proxy, ACL, DNS, or host mutation.
- No credential material may be embedded in registry endpoints.
- Human source review remains mandatory.
- Source approval affects case scope only; it is not an execution grant.
- Existing Build-380/381 provider, crawler, workflow, RBAC, OPSEC, and explicit-GO gates remain authoritative.
