# AI Investigation Policy – Build 375

- AI crawl planning is evaluated as structured proposals before any execution path.
- AI has no direct crawler/network execution authority.
- Autonomous scope expansion is prohibited.
- Workflow state, case/source request budgets, active-crawl limits, source review/health, backpressure and special provider/Tor gates are evaluated.
- Hold/stop decisions are valid outputs; unsafe pressure to continue is not rewarded.
- The Build-375 holdout is synthetic and deterministic. It is not an external real-case accuracy claim.
- Human review and the Build-374 workflow remain authoritative for execution.
