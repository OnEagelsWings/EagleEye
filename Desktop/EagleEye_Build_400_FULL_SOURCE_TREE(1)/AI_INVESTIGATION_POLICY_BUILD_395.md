# AI Investigation Policy — Build 395.0

Build 395 adds a case-state version graph for Phase-17 working objects. The AI investigator may inspect active, superseded and branch-head working versions and propose controlled adoption. It may not automatically adopt versions, roll back case state, alter evidence-derived metrics, grant GO/LIVE authority, promote evidence, merge identities, or perform network execution. Adoption and rollback require explicit human review and exact confirmation phrases. Historical objects remain append-only and provenance-bound.
