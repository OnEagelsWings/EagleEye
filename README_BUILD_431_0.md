# EagleEye Build 431.0 — News Provenance & Syndication Analysis

Build 431 adds deterministic provenance and syndication analysis on top of normalized Build-429 news items and Build-430 machine extractions. It identifies exact-content reuse, shared acquisition lineage, same-source/same-host families, and high claim-overlap candidates.

The analysis is deliberately conservative: exact content identity and shared acquisition lineage are strong non-independence signals; same-source, same-host and claim overlap do not by themselves prove syndication or common editorial control. Publisher strings remain source claims rather than verified ownership facts.

Build 431 has no network authority and does not promote machine analysis to truth. Production readiness remains false.
