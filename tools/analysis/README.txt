EagleEye – Lokale Analyse

Windows: EagleEye-Analyse.cmd starten. Python 3.11 oder neuer und die gewünschten Analyseprogramme im PATH werden benötigt. „Werkzeug“ zeigt fehlende Programme an.
Kali: Im entpackten Ordner „sh Kali-einrichten.sh“ ausführen. Bei späteren Starts genügt „python3 bridge.py“. Der Browser im Gast erreicht den lokalen Dienst unter http://127.0.0.1:48137. Für direkten Austausch die Sites-Seite im selben Betriebssystem öffnen. Zwischen Windows und VM ist der Befundimport per JSON möglich.
Sites: In einer Fallakte „Analysewerkzeuge“ öffnen. Werkzeug auswählen, lokalen Arbeitsplatz öffnen und Dateien oder einen Benutzernamen angeben. „Befund an Sites übergeben“ zeigt eine Vorschau in der Site. Nach Prüfung als Beleg speichern. Alternativ die lokale befund.json importieren.
Ergebnisse liegen unter EagleEye-Analysen im Benutzerordner. Für ein anderes Laufwerk EAGLEEYE_ANALYSIS_HOME setzen. Zum Beenden das Konsolenfenster schließen.
