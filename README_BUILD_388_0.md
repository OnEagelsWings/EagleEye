# EagleEye Build 388.0 — Governed Research Waves

Build 388 adds a persistent research-wave session layer over Builds 384–387. It binds a wave plan to an acquisition packet, attaches one-time controlled dispatches, observes worker results and stored artifacts, records evidence-linked coverage observations, and returns a continuation decision.

A new wave still requires explicit investigator action and the existing GO/LIVE chain. Build 388 itself performs no external fetch and no worker claim.
