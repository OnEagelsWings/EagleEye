# EagleEye Build 414.0 — Autonomous Research Waves
Build 414 introduces bounded autonomous research-wave orchestration on top of the immutable Build-413 Investigation Planner. A run is case-scoped, budget-bounded, provenance-aware and remains dormant until an authenticated investigator supplies the explicit `AUTHORIZE RESEARCH WAVES` confirmation. The autonomy envelope cannot expand case scope, issue GO, promote evidence, determine truth, or directly perform network I/O. Remote collection remains delegated to separately governed execution layers.
