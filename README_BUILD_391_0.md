# EagleEye Intelligence Platform — Build 391.0

## AI Investigation Synthesis

Build 391 connects Phase-17 evidence candidates and source-independence reviews to a structured investigation synthesis layer.

A finalized Build-390 corroboration review can be synthesized into a **candidate claim**. Supporting observations and counterevidence remain linked to their source-independence groups. A reviewed candidate claim may be used to create a **hypothesis proposal** with an explicit test plan. Hypotheses remain `hypothesis_not_fact` throughout Build 391.

Reviewed claims and retained-for-testing hypotheses can be admitted to the existing Investigation Kernel as notebook/event work objects after explicit confirmation. Build 391 intentionally avoids the legacy numerical hypothesis confidence path.

### Safety / governance invariants

- no automatic truth acceptance;
- no truth probability;
- no automatic claim acceptance;
- no automatic evidence promotion;
- no automatic identity merge;
- no direct network fetch;
- no new GO grant or crawler job;
- explicit confirmations for claim review, hypothesis review, kernel admission, and persistent synthesis snapshots.
