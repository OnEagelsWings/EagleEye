# EagleEye Build 430.0 — News Entity/Event Extraction

Build 430 adds a provenance-bound extraction layer for entities, events and claims found in normalized Build-429 news items. Extractor identity/version and confidence values are retained. Extracted claims default to uncorroborated and machine extraction is explicitly an observation, not a fact determination.

Build 430 is the Phase-19 hard checkpoint for Builds 426–430. Before Build 431, the cumulative chain must pass current-head CI, regression and review. Production readiness remains false.
