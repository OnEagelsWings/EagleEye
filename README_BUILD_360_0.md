# EagleEye Intelligence Platform — Build 360.0

Build 360 closes Phase 15 as an internally qualified **controlled local pilot candidate**.

Start with `START_EAGLEEYE_PRO.bat` on Windows or `START_EAGLEEYE_PRO.sh` on Unix-like systems. The workspace binds to loopback only. Initial setup creates the first local Argon2id system administrator.

This release is **not** declared production-ready. Read `FINAL_READINESS_ASSESSMENT_BUILD_360.md` and `ACCEPTANCE_RESULTS_BUILD_360_0.json` for the exact validation boundary.
