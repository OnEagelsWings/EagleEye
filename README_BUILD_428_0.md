# EagleEye Build 428.0 — Archives & Historical Web

Build 428 introduces a provenance-preserving historical-web layer. Public archive sources are registered through Build 421, retrievals remain Build-422 acquisition events and Build-423 content objects, while Build 428 records the original URL, archive URL, archive provider and historical capture time.

Archive captures can be ordered into a case-scoped timeline. The model distinguishes the archive's historical observation from evidential truth: a capture proves what the archive returned and when it claims the source was captured; it does not by itself establish that the archived statement was true.

Build 428 has no network authority and performs no archive access-control bypass. Live archive connectors/retrieval adapters remain governed by the crawler acquisition boundary.
